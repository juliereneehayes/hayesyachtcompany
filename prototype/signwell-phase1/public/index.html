Prototype boundaries and test notes
All names and emails are synthetic @example.com addresses. Provider mode is disabled unless explicitly configured with a SignWell API key, a test template ID, and SIGNWELL_TEST_MODE=true. Test Mode is sent with both draft creation and the later send call. No customer email should be entered here.
Embedded signing may disable SignWell email authentication. HYC must separately authenticate the owner magic link and verify signer identity before issuing an embedded session; the prototype's test iframe is not identity proof.
