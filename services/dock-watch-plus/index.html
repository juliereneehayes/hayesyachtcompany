Who Dock Watch Plus is for

Dock Watch Plus is for owners of 30–60 ft boats who want HYC aboard every week and one engine run each month as part of the recurring plan.

What’s included

  • One full aboard check each week
  • One engine run each month
  • Documented photo updates through Boat Binder

Photo documentation & updates

Each scheduled visit includes photo documentation managed through Boat Binder, giving you an ongoing record of HYC’s visits and observations.

Important considerations

The plan includes one engine run per month. It does not include additional engine runs, maintenance, repairs, or diagnostic work. Those services are separate from the monthly plan.
